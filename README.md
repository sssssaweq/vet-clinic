# vet-clinic - система учета ветеринарных осмотров
Информационная система для учета животных и ветеринарных осмотров с модулем прогнозирования риска заболеваний.


## Технологии
- Python
- SQL Server
- Streamlit
- scikit-learn, LightGBM

## Автор
Гришин Артем Витальевич

## Описание проекта

В хозяйстве ведётся учёт животных и ветеринарных осмотров. Сейчас записи хранятся в бумажных журналах или разрозненных Excel-файлах, из-за чего ветеринар не видит полную историю животного, а повторные заболевания выявляются с задержкой.

Система автоматизирует учёт осмотров и помогает заранее выявлять животных с повышенным риском заболевания на основе истории осмотров, возраста, продуктивности и других признаков.

## Цель проекта

Разработать информационную систему учёта ветеринарных осмотров, которая хранит данные о животных и осмотрах, формирует отчёты и прогнозирует риск заболевания животного с помощью модели машинного обучения.

- **500 осмотров**
- **10 ветеринаров**
- **21 диагноз** (включая «Здоров»)
